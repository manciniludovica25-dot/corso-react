# Corso React

Repository con materiale, esercizi e progetti del corso di **React**.

## Contenuti
- App di esempio
- Esercizi per le lezioni
- Appunti/risorse utili

## Requisiti
- Node.js (consigliato: versione LTS)
- npm (o yarn/pnpm)

## Avvio di un progetto (Create React App o Vite)
Apri la cartella del progetto e lancia:

```bash
npm install
npm run dev
```

> Se il progetto usa Create React App, il comando può essere:
```bash
npm start
```

## Struttura (esempio)
- `lezioni/` → codice visto a lezione
- `esercizi/` → esercizi svolti/da svolgere
- `progetti/` → mini-progetti o progetto finale
- `appunti/` → note e link

## Note
Se trovi errori o vuoi migliorare qualcosa, apri una issue o una pull request.
